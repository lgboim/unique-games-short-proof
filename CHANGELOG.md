# Changelog

All notable public changes to this repository are documented here. Changes to a paper are released as a new Zenodo version and listed here.

## Unreleased

## 1.0.0 — 2026-10-09

- First public repository. It holds the two preprints and the companion note with their LaTeX sources (`papers/`), and the script and logs of the Comparator check of OpenAI's Lean 4 formalization (`lean_check/`). All nine files are byte-identical to the Zenodo deposits.
- Added citation and research metadata (`CITATION.cff`, `codemeta.json`), contribution and security guidance, a SHA-256 manifest with a checker that also verifies the Zenodo checksums, issue and pull-request templates, and an automated repository-quality workflow.
- Replaced the combined `LICENSE` file with `LICENSE-CODE.txt` (MIT), `LICENSE-DOCUMENTATION-DATA.txt` (CC BY 4.0) and `LICENSE-SCOPE.md`.
